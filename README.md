# Spendly

1日ごとの出費合計とカテゴリ別の内訳、月ごとの固定費を記録・集計する個人用の家計簿アプリです。Next.js / React / TypeScript / Tailwind CSS / Prisma / PostgreSQL を使用しています。

## できること

- 1日の出費合計を先に記録し、その日のカテゴリ・金額・メモを複数行で管理
- 合計と内訳が一致していなくても保存し、差額を表示
- 月ごとの固定費を日々の支出とは別に記録
- 月の総額を「日々の支出」と「固定費」に分けて表示
- 入力済み内訳のカテゴリ別円グラフ・棒グラフ
- 月・カテゴリ・メモによる日別記録の絞り込み
- カテゴリの追加、名前変更、削除。使用中のカテゴリは削除を防止
- スマートフォン用ナビゲーション、入力エラー表示、読み込み・空状態・404・エラー画面

日付の保存・集計は日本時間（JST）を基準にしています。1日の合計は0円以上、各内訳は1円以上、上限は2,147,483,647円です。

## ローカル起動

Node.js 22 以上と PostgreSQL（Neon など）が必要です。

```sh
npm ci
cp .env.example .env
```

`.env` の `DATABASE_URL`（アプリ用）と `DIRECT_URL`（マイグレーション用）を設定します。Neon ではアプリ用に pooled 接続、マイグレーション用に direct 接続を設定できます。

```sh
npx prisma generate
npm run db:deploy
npm run db:seed
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。初期カテゴリの投入は再実行可能です。サンプル支出は `npm run db:seed:demo` で追加できます（通常利用のデータベースでは不要です）。

## 検証と本番ビルド

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

GitHub Actions でも lint・型チェック・テスト・ビルドを実行します。ユニットテストは日付境界、金額上限、入力検証を確認し、データベースを変更しません。

## 運用範囲

単一ユーザーが localhost で使う構成です。標準の起動コマンドは `127.0.0.1` に限定して待ち受けます。ログイン機能・ユーザー間のデータ分離は実装していないため、一般公開する場合は認証・アクセス制御を追加してください。

接続情報を含む `.env`、ローカルキャッシュ、データベースの内容は Git 管理から除外します。リポジトリから再現するときは、自分のデータベース接続情報を設定してください。
